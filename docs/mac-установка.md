# Установка Proxya Desktop на macOS

Сборка для Apple Silicon. Подпись ad-hoc, без Apple Developer ID, поэтому
Gatekeeper может сказать, что разработчик не подтверждён или что приложение
повреждено.

## Установка

1. Скачайте `Proxya-macos-arm64.tar.gz` со страницы
   [релизов](https://github.com/ProxyaAnty/Proxya-Desktop/releases/latest) и
   сверьте SHA-256 со значением, опубликованным рядом с релизом.
2. Распакуйте и перенесите **Proxya** в **Программы**.
3. В Терминале один раз:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Proxya.app"
   ```

4. Откройте Proxya обычным способом.

Если не хотите открывать Терминал, попробуйте запустить приложение, а затем
зайдите в **Системные настройки, Конфиденциальность и безопасность** и
выберите **Открыть всё равно**.

## Служба туннеля

Режиму «Туннель» нужна небольшая служба с правами, которые требует адаптер TUN.
Приложение ставит её при первом включении, и macOS в этот момент спрашивает
пароль администратора. Больше приложение его нигде не спрашивает.

Снять службу потом:

```bash
sudo "/Applications/Proxya.app/Contents/MacOS/proxya-service" uninstall
```

Режиму «Системный прокси» ни служба, ни пароль не нужны.

## Пока туннель поднят

Служба переводит системный DNS на туннель и возвращает прежние адреса при
отключении. Копия прежних настроек лежит на диске, поэтому даже падение не
оставит мак с адресом несуществующего адаптера.

Если на маке есть другой VPN, который сам управляет DNS, например Tailscale со
своим резолвером, его резолвер останется впереди нашего и имена будут
разрешаться мимо туннеля. Два туннеля на одной машине — это конфликт, а не
ошибка. Выключите второй или работайте рядом с ним в режиме «Системный прокси».

## Kill Switch

Kill Switch пока только на Windows. На macOS он скрыт, а не показан
переключателем, который ничего не делает.

## Где лежат данные

`~/Library/Application Support/Proxya` у приложения и
`/Library/Application Support/Proxya` у службы. Пароли прокси и сессия кабинета
зашифрованы ключом из Keychain, поэтому копия папки на другом маке не даёт ни
доступа к кабинету, ни паролей от прокси.
